# 📚 Sistema de Preguntas - Saber Pro (Laboratorio de Ingeniería de Software 2)

Sistema web para la preparación y evaluación en pruebas **Saber Pro**, enfocado en la gestión de usuarios, banco de preguntas y simulación de exámenes.

---

## 🚀 Características

- **Gestión de Usuarios:** Registro, inicio de sesión y administración de roles.
- **Módulo de Interfaz:** Interfaz intuitiva e interactiva para la resolución de módulos Saber Pro.
- **Banco de Preguntas:** Almacenamiento y categorización de preguntas por áreas de conocimiento.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje Principal:** Java / HTML / CSS / JavaScript
- **Gestión de Versiones:** Git & GitHub
